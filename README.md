# 말랑콩떡 · 함께 쓰는 매장 노트

말랑콩떡의 예약 주문부터 생산 준비, 재고 확인, 마감까지 돕는 **떡집 운영 보조 에이전트**입니다. 주문과 재고를 바탕으로 필요한 생산량과 재료를 계산하고, AI가 추가로 만들 메뉴를 제안합니다. 매장 운영자가 계획을 검토·확정하고 실제 생산 결과를 기록합니다.

아이폰·안드로이드·PC에서 사용하는 웹 앱이며, 휴대폰 홈 화면에 추가해 사용할 수 있습니다.

## 1. 누구를 위한 에이전트인가요?

- **말랑콩떡 사장님과 함께 일하는 운영자:** 한 매장을 두 사람이 함께 관리하는 상황을 기준으로 만들었습니다.
- **예약과 현장 판매를 함께 준비하는 떡집:** 예약 수량, 진열할 수량, 남아 있는 완제품을 함께 보고 오늘 만들 양을 결정할 수 있습니다.
- **주문장·생산표·재고장을 따로 관리하던 사용자:** 같은 주문을 여러 번 옮겨 적거나 필요한 재료를 수작업으로 합산하는 일을 줄입니다.

## 2. 어떤 업무를 대신하나요?

| 업무           | 에이전트가 돕는 일                                                           | 운영자가 하는 일                              |
| -------------- | ---------------------------------------------------------------------------- | --------------------------------------------- |
| 예약 정리      | 개·박스·선물세트 주문을 모아 날짜별 수량을 집계                              | 고객 주문을 입력하고 변경·취소·수령 상태 확인 |
| 고객 안내      | 주문 내용·수령 방식·입금 계좌를 담은 안내 문구 작성                          | 문구 검토·수정 후 문자 앱 등에서 전송         |
| 생산 준비      | 예약·진열 목표·가용 완제품을 반영해 생산 단위별 필요량 계산                  | 레시피·생산 기준 등록, 계획 검토·확정         |
| 추가 메뉴 선택 | 재고·예약·최근 생산 이력을 고려한 AI 추천과 재료 부족 검증                   | 추천안을 검토하고 생산계획에 반영             |
| 재고 관리      | 생산 완료 시 재료 차감, 수령 시 완제품 차감, 향후 재료 부족량·첫 부족일 계산 | 입출고·실사와 실제 생산량·재료 사용량 기록    |
| 마감 정리      | 생산분별 잔량·폐기·기타 출고를 모아 판매 추정량 계산                         | 실제 남은 수량과 폐기량 입력                  |

AI 추천은 연결 설정이 필요합니다. AI는 추천안을 제시하며, 계획 저장과 생산 완료는 운영자가 결정합니다. 재료 부족 예측은 등록된 주문과 생산 기준에 따른 계산이고, 마감의 판매 추정량은 POS 매출과 다를 수 있습니다.

## 3. 현재 완료된 것과 남은 것

아래는 현재 코드의 구현 상태입니다. 기능 구현 완료와 실제 매장 환경에서의 연결·검증 완료를 구분합니다.

### 구현 완료

- [x] 예약 등록·수정·취소·수령 처리와 개·박스·선물세트 수량 환산
- [x] 고객 정보, 픽업·퀵·배달 방식, 주소, 스티커 문구와 참고 이미지 보관
- [x] 주문 안내 문구 생성·수정·복사와 문자 앱 열기
- [x] 마이크로 말한 주문을 Realtime으로 인식해 주문 초안 작성 — 실제 사용에는 OpenAI 연결과 마이크 권한 필요
- [x] 메뉴판 36종의 이름·가격·포장 수량·사진 등록과 메뉴별 레시피·생산 기준 편집
- [x] 예약·진열 목표·가용 완제품을 반영한 날짜별 생산량 계산과 계획 확정
- [x] 실제 생산 결과 기록과 재료 차감, 재료 부족·변경된 조건 검증
- [x] AI 추가 메뉴 추천과 추천안 검증 — 실제 사용에는 AI 연결 필요
- [x] 재료·비품 입출고·실사 보정과 기간별 재료 부족 예측
- [x] 생산분별 완제품 관리, 수령 차감·되돌리기, 잔량·폐기 마감 기록
- [x] 두 사용자 로그인·매장 데이터 공유와 저장 충돌 감지 — 실제 사용에는 Supabase 연결 필요
- [x] 브라우저에 저장되는 체험 모드, 매장 기록 JSON 백업 다운로드
- [x] 홈 화면 설치를 위한 PWA 구성과 연결 실패 안내
- [x] 주문·생산·재고 계산, 메뉴 갱신, 안내 문구, DB 권한·저장 충돌 자동 테스트 코드

### 실제 운영 전 설정·확인 필요

이 저장소의 코드와 문서만으로 실제 서비스에서의 완료 여부를 확인할 수 없어 남은 항목으로 표시합니다.

- [ ] 실제 매장의 재료·초기 재고·메뉴별 레시피·생산량·추천 기준 등록
- [ ] 운영 Supabase 연결, 두 사용자 초대·로그인·비밀번호 설정, 기기 간 공유와 이미지 저장 확인
- [ ] 운영 AI 연결과 실제 매장 데이터로 추천 결과 확인
- [ ] 배포 주소에서 아이폰·안드로이드 홈 화면 설치와 주문→생산→수령→마감 전체 흐름 확인
