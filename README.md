# 말랑콩떡 · 함께 쓰는 매장 노트

말랑콩떡의 예약 주문부터 생산 준비, 재고 확인, 마감과 스티커 작업까지 돕는 **떡집 운영 보조 에이전트**입니다. 주문과 재고를 바탕으로 필요한 생산량과 재료를 계산하고, AI가 음성 주문 입력과 추가 메뉴 추천을 돕습니다. 매장 운영자가 주문 초안과 생산계획을 검토·확정하고 실제 생산 결과를 기록합니다.

아이폰·안드로이드·PC에서 사용하는 웹 앱이며, 휴대폰 홈 화면에 추가해 사용할 수 있습니다.

현재는 말랑콩떡 한 매장의 사용과 AI 체험에 집중합니다. 다른 매장의 가입·연결 흐름은 추후 범위입니다.

## 1. 누구를 위한 에이전트인가요?

- **말랑콩떡 사장님과 함께 일하는 운영자:** 한 매장을 두 사람이 함께 관리하는 상황을 기준으로 만들었습니다.
- **예약과 현장 판매를 함께 준비하는 떡집:** 예약 수량, 진열할 수량, 남아 있는 완제품을 함께 보고 오늘 만들 양을 결정할 수 있습니다.
- **주문장·생산표·재고장을 따로 관리하던 사용자:** 같은 주문을 여러 번 옮겨 적거나 필요한 재료를 수작업으로 합산하는 일을 줄입니다.

## 2. 어떤 업무를 대신하나요?

| 업무           | 에이전트가 돕는 일                                                           | 운영자가 하는 일                                                   |
| -------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 예약 정리      | 음성으로 주문 초안을 작성하고 개·박스·선물세트 주문을 날짜별로 집계          | 직접 입력하거나 음성 초안을 검토·저장하고 변경·취소·수령 상태 확인 |
| 고객 안내      | 주문 내용·수령 방식·입금 계좌를 담은 안내 문구 작성                          | 문구 검토·수정 후 문자 앱 등에서 전송                              |
| 생산 준비      | 예약·진열 목표·가용 완제품을 반영해 생산 단위별 필요량 계산                  | 레시피·생산 기준 등록, 계획 검토·확정                              |
| 추가 메뉴 선택 | 재고·예약·최근 생산 이력을 고려한 AI 추천과 재료 부족 검증                   | 추천안을 검토하고 생산계획에 반영                                  |
| 재고 관리      | 생산 완료 시 재료 차감, 수령 시 완제품 차감, 향후 재료 부족량·첫 부족일 계산 | 입출고·실사와 실제 생산량·재료 사용량 기록                         |
| 마감 정리      | 생산분별 잔량·폐기·기타 출고를 모아 판매 추정량 계산                         | 실제 남은 수량과 폐기량 입력                                       |
| 스티커 작업    | 저장한 템플릿에 주문 문구를 불러오고 완성 이미지를 복사                      | 기기 사진을 올려 템플릿 관리, 사진·문구 배치 편집                  |

음성 입력과 AI 추천은 OpenAI 연결 설정이 필요하며, 음성 입력에는 마이크 권한도 필요합니다. 주문 초안 저장과 생산계획 확정·완료는 운영자가 결정합니다. 재료 부족 예측은 등록된 주문과 생산 기준에 따른 계산이고, 마감의 판매 추정량은 POS 매출과 다를 수 있습니다.

**말랑콩떡 AI 체험:** Supabase 설정 없이 실행하면 메뉴별 가상 레시피·재고·이번 달 주문·최근 생산 및 마감 기록·추천 기준이 자동으로 채워집니다. OpenAI 키만 연결한 뒤 **생산계획 → AI 메뉴 추천 → 추천안을 생산계획에서 검토**로 사용합니다. 가상 레시피와 생산량은 실제 매장 기준으로 사용하기 전에 확인해야 합니다. [체험 실행 방법](docs/development-and-operations.md#말랑콩떡-ai-바로-체험)

생산계획 상단의 **AI 메뉴 추천**에서 메뉴·추천 개수·이유를 확인합니다. 필요한 생산 메뉴와 계획 메뉴는 수량을 맞춰 정렬한 목록으로 표시하며, 메뉴 행을 누르면 예약·가용 완제품·진열 목표 등 계산 근거가 펼쳐집니다. 계획 작성 창에서도 메뉴별 생산 단위와 완성 수량을 함께 비교할 수 있습니다.

스티커는 **기기에 있는 사진을 올려 재사용 템플릿으로 관리하는 방식**입니다. AI로 스티커 사진을 생성하는 기능은 개발 범위에서 제외합니다.

### 실제 운영 전 설정·확인 필요

이 저장소의 코드와 문서만으로 실제 서비스에서의 완료 여부를 확인할 수 없어 남은 항목으로 표시합니다.

- [ ] 실제 매장의 재료·초기 재고·메뉴별 레시피·생산량·추천 기준 등록
- [ ] 운영 Supabase 연결, 두 사용자 초대·로그인·비밀번호 설정, 기기 간 공유와 이미지 저장 확인
- [ ] 운영 AI 연결과 실제 매장 데이터로 추가 메뉴 추천·음성 주문 초안 확인
- [ ] 실제 기기에서 스티커 사진 업로드·템플릿 재사용·이미지 복사와 보관 기간 만료 처리 확인
- [ ] 배포 주소에서 아이폰·안드로이드 홈 화면 설치와 주문→생산→수령→마감 전체 흐름 확인
